## Events

Event tickets let a team of players sign up together. Events have their own ticket category, separate from your normal ones.

1. Open the dashboard, pick your server and click **Events** (or run `/event setup category:<Discord category>`). Choose the Discord category for event tickets, the staff roles that can see them, and who can post panels.
2. Event staff run `/event panel title:Puzzle Night team-size:4` in the event channel.
3. Players press **Join event**, pick their teammates (or press **Play solo**), and get a private ticket named after the team and event, e.g. `frozedy-alex-puzzles`.

- Posting a panel needs an event manager role (set on the Events page or with `/event roles add`). Admins and any role named "Event Manager" can always post panels.
- Joining an event needs no role. A player can't sign up twice for the same event, but can join different events at the same time.
- Use `{team}`, `{event}` and `{number}` in the event channel name setting to change how channels are named.
- `/event roles list` shows the current setup.

## Dashboard

The server page on the dashboard has extra tiles:

- **Stats**: tickets over time, response and resolution times, ratings, busiest hours and days, categories and top staff, for 7 days to a year.
- **Events**: event settings, signed-up teams and recently finished event tickets.
- **Ticket history**: search and browse every ticket and its transcript.
- **Ratings**: all ticket ratings and comments.
